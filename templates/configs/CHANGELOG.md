## How to use this file

- **[Unreleased]**: Changes that are in development but not yet released
- **[X.Y.Z] - YYYY-MM-DD**: Released versions with their changes

### Categories:
- **Added**: New features
- **Changed**: Changes in existing functionality
- **Deprecated**: Soon-to-be removed features
- **Removed**: Removed features
- **Fixed**: Bug fixes
- **Security**: Security improvements

### Example:

```markdown
## [1.0.0] - 2024-01-15

### Added
- User authentication with JWT tokens
- Dashboard with analytics
- Dark mode support

### Changed
- Updated login UI design
- Improved API error handling

### Fixed
- Fixed memory leak in useEffect hook
- Resolved routing issue on Safari

### Security
- Added CSRF protection
- Updated dependencies with security patches
```
